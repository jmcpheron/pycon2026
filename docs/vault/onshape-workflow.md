# Onshape workflow — making the SVGs match a real CAD model

The diagrams in this section are generated from Python so they always
match the parameters in [`src/vault/vault.py`](../../src/vault/vault.py).
For the *physical* mechanism, the same parameters drive an Onshape
parametric model. This page documents the convention so the two stay in
sync.

## Suggested phasing

The model is a study, not a product, so it's worth building it in
discardable phases.

### Phase 1 — Static layout
* Circular door slab driven by `#door_diameter` and `#door_thickness`.
* Pin holes via a circular pattern of `#pin_count` instances at
  `#pin_radius`.
* Central hub at `#hub_diameter`.

### Phase 2 — Radial pin motion
* Pins as separate parts.
* Slider mates pinning each pin to a radial axis.
* Animate pins between fully-extended and fully-retracted.

### Phase 3 — One actuator concept
Pick *one* of these to model first. The vault SVG study deliberately
stays neutral about which is "right":

1. **Central cam plate with radial slots** — easiest to visualise, hard
   to tune.
2. **Rack-and-pinion** ring — clean linear motion, more parts.
3. **Rotating ring with angled slots** — compact, follows pin centres.
4. **Linkages from a central wheel to each pin** — most parts, easiest to
   reason about per-pin force.

### Phase 4 — Compare 12 vs. 13

Use Onshape *configurations* (or two parallel Part Studios) to keep both
counts in one document:

```
Vault Door · 12 pins
Vault Door · 13 pins
Vault Door · 24 pins
```

The 13-pin configuration doesn't have to be fully
functional. A static layout study is enough to show the design problems
documented in [the 13-pin problem](thirteen-pin-problem.md).

## Exporting back to this repo

When you have a STEP export you're happy with, drop it next to
`jmcpheron-card.step` and (eventually) wire up a `cardlab`-style
explode pipeline. For now the SVG study and any Onshape screenshots
live side by side under `docs/vault/` — the SVGs answer "what should
the mechanism look like?" and the screenshots answer "does it close?"
