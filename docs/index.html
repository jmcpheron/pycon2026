§ Reduction-gear card

pycon2026

A 256:1 compound reduction chain, in a card, deconstructed by Python.

Five stages of 4:1 spur-gear reduction, packed flat into a 78 × 44 mm body. The STEP file is designed in Onshape; everything else — exploded animation, per-part renders, engineering writeups — is regenerated by Python on every push.

§ 01

The pipeline

Onshape as the parametric design surface. Python as the deconstruction layer. GitHub Actions as the build server. The plate above is the artifact. 

$ uv run stepforge inspect jmcpheron-card.step
# → AP242 schema, assembly tree, bounding box, tessellation stats

$ uv run stepforge explode --in jmcpheron-card.step --out docs/assets/card/
# → parts/*.{stl,glb,png}, exploded.{glb,gif}, manifest.toml

Both commands run in CI via the Build Card workflow — Ubuntu runner, OpenSCAD installed from apt, xvfb for the headless GL context, then uv run stepforge … drives both. The resulting GIF, GLB, and per-part PNGs are committed back to the repo automatically, so what you see at the top of this page always matches the source jmcpheron-card.step.

Push a new Onshape export and the hero animation regenerates within a minute. Fork the repo, edit the STEP file, and the workflow rebuilds your version — no local OpenCascade install required.

§ 02

The explainers

The geometry doesn't carry its own design intent. The Python does.

Short, deterministic programs under src/explainers/ produce the engineering writeups for the card. The math, diagrams, and tables come from one canonical card.py — change a number there, every page reflects it on the next build.

  • The card in 3D — canonical STEP source and the stepforge pipeline.
  • Gear ratios — compound 4:1 × 5 = 256:1, with a thumb-travel intuition.
  • Decoding the gears from STEP — FFT the radial profile of an STL slice to recover tooth count and module from geometry alone.
  • Stacking — why a 3-level cycle of hub heights keeps the card thin.
  • Terminology — pinion, module, pitch circle, addendum.
  • Printing considerations — orientation, chamfers, separate posts.
